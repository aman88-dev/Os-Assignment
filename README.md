Operating Systems Lab
This Jupyter notebook (aman.ipynb) contains 11 Python programs demonstrating operating system concepts.
Topics Covered
- Process creation and multithreading
- CPU and disk scheduling
- Process synchronization and deadlock avoidance
- Memory allocation and page replacement
- File allocation methods
How to Run
Open the notebook in Jupyter Notebook or Google Colab and execute the cells individually. Program 1 requires a Unix-like environment (such as Linux).
